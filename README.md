# 知识回响 · 前端首页原型

这是「知识回响」的独立前端设计迭代仓库。当前以 **根目录 `index.html`** 作为唯一迭代入口，不需要安装依赖。

## 已有功能（前端 Mock）

- 三个案例：颈椎结构、摄影曝光、睡眠机制
- 鼠标左键拖动 / 触控滑动 / 键盘方向键切换案例，居中吸附，左右对称预览
- 浅色默认与夜间模式切换
- 「开启知识回响」后的知识画布预览
- 演示文章与 AI 内容均为 Mock，并非真实知乎资料或已接入的后端功能

## 查看与修改

- 本地：下载或克隆仓库，用 Chrome/Edge 打开 `index.html`。
- 后续 UI 修改直接更新 `main/index.html`，不再生成多个平行版本。
- 当前首页主要用于定稿视觉与交互；正式 2D/3D 和 AI 后端接入尚待实现。

## 在线预览（可选）

如果仓库支持 GitHub Pages，可以进入 **Settings → Pages**，选择 **Deploy from a branch → main → /(root)**，保存并等待部署。**当前仓库为 Private**，请先确认账号对私有仓库 Pages 的支持和演示内容公开范围；未启用前没有可用的固定在线预览网址。

## 版本原则

每次迭代注明界面变更。不要将示例答主、来源链接、医学模型、AI 答案当作已核实的真实信息。
